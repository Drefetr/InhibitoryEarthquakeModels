# Reproducibility checks

This directory retains compact results useful for checking the shipped manuscript and code:

- `unit_tests.txt`: three fixed-input tests (imports, kernel normalization and exact Poisson exposure).
- `mathematics.json`: selected deterministic algebra, quadrature and arithmetic examples; not certification of every theorem or historical experiment.
- `production_checks.json`, `visual_review.json` and `toolchain.json`: current65-page manuscript and2-page supplement production results and tested build environment. The historical TeX cache was not snapshotted.
- `privacy_audit.json`, `data_exclusion_scan.json` and `external_input_preflight.txt`: public payload/input-exclusion scope. External scientific inputs remain separately required.
- `documentation_checks.json`: earlier documentation check record; current membership is authoritative in `MANIFEST.json`.

The accepted source/PDF bytes are retained during packaging cleanup. Detailed review correspondence, adjudications, agent task records, raw execution logs and renders are maintained locally outside this repository. These checks do not reproduce missing historical history banks or establish a physical mechanism. Run the commands in the main README to check a fresh checkout; no refits or simulations are needed for those checks.
