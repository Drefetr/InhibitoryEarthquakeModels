# Recovered numerical methods

This supplement describes saved procedures and deterministic metadata extraction. No history generation, optimization, likelihood reevaluation or catalogue collection was performed for this revision. `methods_settings.json` binds exact source hashes, parameter contracts and finite-mixture arrays. The portable arrays are newly computed from the recovered source formula; they are not historical result records.

## Kernels

The generating kernel uses alpha=0.5, tau=1 day, spectral step s=0.4 and tail setting epsilon=1e-8. Define C=4*sin(pi*alpha)/(pi*alpha), J=ceil(max(log(4)/alpha,log(C/epsilon)/alpha)/s), v_j=s*j for j=-J,...,J, and rho_j=exp(v_j)/tau. Raw weights are s*sin(pi*alpha)/(2*pi*(cosh(alpha*v_j)+cos(pi*alpha))); halve the two endpoints, then divide all weights by their finite sum. This gives J=97 and 195 modes for alpha 0.5; the same rule gives 137 modes for candidate alpha 0.7. Rates have units day^-1 and weights sum to one. Phi(u)=sum w_j exp(-rho_j*u), h(u)=sum w_j*rho_j exp(-rho_j*u)=-Phi'(u). This finite model has finite h(0). The tail setting is part of spectral construction, not a universal bound on inference error or an exact singular-memory implementation.

## Simulator and precise clock

The accepted simulator uses exponential proposals with envelope exp(a+abs(d))+sum w_q*E_q. Modal excitation decays between proposals; inhibition is nonnegative and the background is bounded by exp(a+abs(d)), so the displayed envelope controls the intervening rate. Both states start at zero. Advance the proposal clock and decay states, evaluate predictable intensity, accept by thinning, and only then draw the fresh Exp(beta) excess mark. Its productivity and stress increments affect later states. A horizon-crossing proposal adds no event.

Every sampled binary64 proposal wait is also accumulated as Decimal.from_float(dt) under precision 1600. The legacy Kahan-style binary64 projection remains the background coordinate. Accepted events retain its residual, exact clock string and positive relative event gap. Projected ties are retained when the positive-gap and two-part clock checks pass, without jitter, merging or resampling. Checkpoint exact_clock may include an unaccepted horizon-crossing proposal; accepted last_event/exact strings identify event clocks. Unrepresentable waits, exhausted clock resolution, consumed-mark transform overflow and resource caps stop with explicit reasons. Overflow does not authorize a replacement mark; restart preserves the prefix and random state.

## History geometry and likelihood

Intervals include the initial quiet exposure, every event gap and final exposure to the horizon. Within each interval, insert all offsets shorter than its duration from geomspace(1e-6,1e5,23) and the geometric means of adjacent offsets, alongside both endpoints. Use Gauss-Legendre order 16 on each resulting subpanel. Selected-point controls use CPU order 32; the oracle refinement rule can require order 64. These are empirical numerical sensitivity controls, not universal integration bounds.

For each modal feature, decay across the authoritative positive gap, read the pre-event state, then add that event's mark. The triggering compensator is evaluated by the finite-mixture CDF, using -expm1(-rho*duration); quiet exposure and the last no-event interval remain included. Event log intensity uses logaddexp of background and triggering terms, with an explicit n=0 branch. Stable value/face routines never clip an unrepresentable gradient or mark transform to create convergence.

## Distinct fitting procedures

The historical fuller saved fits used the actual iteration16 call with include_omori=False: exponential tau in {0.1,1,10} days; Mittag-Leffler alpha in {0.5,0.7}, tau in {0.1,1,10}; and productivity ratio r in {0.4,0.7,0.8}. Exponential cells are null-only: inhibitory alternatives are constructed only for ML triggers (the explicit loop is for k in ml). Stress is ML, retaining trigger alpha and using tau multipliers 1,0.1,10. Beta is the realized-history mark-only estimate 1/mean(excess), outside the optimizer. Continuous bounds are a[-12,0], d[-2,2], n[0,.98] and eta[0,3]. Let a_seed=clip(log(max(N,1)*.6/(end-start)),-11.5,-.1). Null starts are(a_seed,0,.35) and(a_seed-.5,.1,.7); stress starts take the matching selected null and append eta 0 or 0.2. Explicit eta0 boundaries and shared-subset floors remain eligible. The actual completed-grid requirement is 162 optimizer records and 234 total subfits, distinct from generic routine defaults that also list Omori.

The primary solver is L-BFGS-B with maxiter100, maxls40, ftol1e-10 and gtol2e-6. Only unsuccessful primary starts receive same-original-start CPU retries with maxls40 then200. After complete previous recovery failure, the accepted amendment uses bounded Powell(maxiter100,maxfev2000,ftol1e-10,xtol1e-8) and the exact n=0 face with L-BFGS-B(maxls200), requiring both declared solvers where applicable. Eligible recoveries require success, feasibility, finite values, strict1e-4 objective agreement and1e-8 nonworsening. Each amended recovery has a 90-second cap or the earlier fit deadline. Independent selected CPU32 controls remain required; no global optimum is asserted.

The two later staged procedures fix beta, n, r and both kernels. The eta-only procedure runs two optimizations, initialized at eta=0 and eta=0.2. The level-and-trend procedure runs two null optimizations, selects the better null fit, then runs two alternative optimizations from that one selected null, initialized at eta=0 and eta=0.2. Thus the level-and-trend procedure has four prescribed optimizations; the two procedures together have six. The level-only procedure fixes d and triggering, profiles a in[-12,0], and searches eta[0,3] with 17 equally spaced mesh points plus saved supplied-background eta and zero, refining nonflat local mesh minima and retaining an 11-point profile. It retains the saved known-known alternative, saved null and its own null as eligible floors. All mandatory solvers must resolve. Its detailed root/scalar tolerances and controls are serialized separately in methods_settings.json.

Observed iteration27 fitting is a separate recipe: five families, strict training prefixes, training-only beta, ML finite grids, a coarse Omori grid followed by bounded continuous Omori refinement, 137 mandatory prescribed optimization slots per training origin, its own stopping options and failure-only recovery. The 15 source-bound selected records, units, transforms, starts and grid winners are in predictive_parameters.json. No historical synthetic parameter or score-derived value fills a selected observed-fit cell.
